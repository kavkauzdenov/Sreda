# Универсальный бот «Среды»

## Принцип

У одного владельца может быть несколько бизнесов. У каждого бизнеса своя отдельная связка Telegram + VK. Решения не создают новых ботов: они подключаются как модули к ботам конкретного бизнеса и меняют их меню, команды и сценарии. Архитектура допускает расширение связки несколькими подключениями в будущем.

Telegram и VK одного бизнеса объединяются в одну пару каналов. Общие настройки и данные хранятся в «Среде», а сообщения отправляются через токен соответствующей площадки. Данные разных бизнесов владельца изолированы.

## Слои

1. **Account & Business Core** — владелец, несколько бизнесов, переключение контекста и разграничение доступа.
2. **Bot Core** — приём событий, маршрутизация, меню, команды, сессии и ответы.
3. **Solution Modules** — заявки, продажи, автопостинг, сообщения администраторам, модерация.
4. **Entitlements** — какие модули активны у бизнеса и до какой даты действует подписка.
5. **Channel Adapters** — Telegram Bot API и VK Callback API.
6. **Business Data** — настройки, заявки, товары, публикации, пользователи и журнал действий.

## Исходящая доставка

Ответ оператора сначала записывается в `communication_message`, затем в той же транзакции ставится в очередь канала (`telegram_outbox` или `vk_outbox`). Отдельные воркеры доставляют очередь через соответствующий API, повторяют временные ошибки с задержкой и блокируют только недоступного получателя. Веб‑приложение не выполняет внешнюю доставку синхронно.

## Модель подключения

- `owner_account` — учётная запись владельца;
- `business` — отдельный бизнес внутри учётной записи;
- `business_connection` — один подключённый канал Telegram или VK;
- `solution` — каталог возможностей;
- `business_solution` — активированная возможность конкретного бизнеса;
- `solution_config` — настройки конкретного модуля;
- `integration_key` — отзывной ключ для связывания каналов;
- `subscription` — срок и статус оплаты для конкретного бизнеса и модуля;
- `business_member` — администратор или оператор с ограниченными правами.

## Динамическое меню

Меню строится при открытии бота из активных модулей. При подключении решения пользователь получает новые кнопки без создания нового бота. При окончании подписки модуль скрывается или переводится в режим продления, а исторические данные сохраняются.

## Бесплатный базовый слой

- связь клиентов с администрацией;
- до 300 сообщений в месяц на бизнес;
- защита от спама и массовых рассылок;
- управление администраторами и операторами.

## Первый MVP

- ядро универсального бота;
- подключение связки Telegram + VK для выбранного бизнеса;
- каталог решений;
- модуль заявок;
- динамическое меню;
- базовая модерация;
- подключаемые платные модули с настраиваемыми тарифами (цены фиксируются отдельно);
- настройки из веб‑интерфейса.

Все последующие модули подключаются поверх этого ядра, не смешивая данные разных бизнесов.

## Безопасность

- токены хранятся только в зашифрованном виде;
- интеграционный ключ можно отозвать и перевыпустить;
- данные изолируются по `business_id`;
- права доступа проверяются на каждом запросе;
- пользовательские сообщения не смешиваются между рабочими пространствами;
- технические ошибки и секреты не отправляются в чат.
