# Запуск Telegram для «Среды»

## До подключения

- Создать бота через `@BotFather`.
- Задать имя, username и описание.
- Установить аватар из `public/assets/sreda/sreda-avatar.png`.
- Сохранить токен только в секретах окружения (не в git и не в чате).

## Проверка в «Среде»

1. Открыть раздел «Подключения».
2. Вставить токен Telegram.
3. Убедиться, что сервис подтвердил имя бота.
4. Завершить настройку приёма заявок.
5. Проверить тестовую заявку из личного чата.

## Включение обработки

- Сначала проверить сайт и PostgreSQL.
- Затем включить Telegram worker.
- После этого запустить Telegram для конкретного бизнес‑пространства.
- Проверить `/start`, `/cancel`, все вопросы формы и появление заявки в разделе «Заявки».

## Переменные окружения

- `TELEGRAM_WEBHOOKS_ENABLED=false` до завершения проверки.
- `TELEGRAM_WEBHOOKS_ENABLED=true` только после создания и проверки бота.
- Токен бота не добавлять в GitHub, логи или клиентский код.

## Критерии готовности

- Бот отвечает на `/start`.
- Некорректные ответы не ломают диалог.
- `/cancel` очищает незавершённую заявку.
- Повторная доставка одного события не создаёт дубликат.
- Новая заявка появляется в PostgreSQL и интерфейсе.
- Ошибка доставки не останавливает все остальные подключения.
